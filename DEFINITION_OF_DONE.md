## 3. Items Requiring Manual Verification

The following operational characteristics cannot be completely validated by a headless node unit test alone:

1. **Browser Visual Canvas Rendering**:
   - *Requirement*: Visual rendering of the chunk ledger canvas grid (up to 32,768 cells) with state colors (committed, in-flight, missing, repairing, failed).
   - *How to Check*: Open `http://127.0.0.1:3000/` in Chrome, Firefox, or Safari, select a test video file (`.mp4`), and visually observe the block grid transition from gray to yellow (in flight) to green (committed).
2. **HTML5 Video Player Hardware Seeking**:
   - *Requirement*: Native `<video>` element scrubbing triggering byte-range requests without stutter.
   - *How to Check*: In the browser UI after finalizing an `.mp4` or `.webm` upload, play the video in the player, click to scrub ahead by 30 seconds, and observe HTTP `206 Partial Content` requests in the browser Network Inspector.
